# Predicting Defective Products in a Factory

## Problem Overview

A factory produces 10,000 electronic components daily. Each product has a 0.004 probability of being defective. Your task is to simulate the defect detection process, calculate the expected number of defects, and compare the results.

## Tasks

1. **Simulate** the defect count using random sampling for 10,000 products.
2. **Calculate** the expected number of defective products using probability.
3. **Compare** the simulated and expected values, and compute the percentage error.

## Input

- Total components (N): 10,000  
- Probability of defect (p): 0.004

## Output

- Simulated defective count  
- Expected defective count  
- Percentage error
